| 항목 | 값 |
| --- | --- |
| 단계 | 6. 알림·화면·마무리 |
| 분류 | 기능 구현 |
| 우선순위 | P2 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-012](T-012.md) 마이그레이션: 변경 기록·발송 이력·알림, [T-058](T-058.md) 단가 변경 이력 기록·조회 |

| 주요 위치 | `app/owner/audit/` |

## 목적

원청과 금액 다툼이 생겼을 때 근거 자료가 된다. 직원 개인을 추적하는 용도가 아니다.

## 요구사항 근거 (설계.md 인용)

> 내부에는 작성 시각, 출력 시각, 재출력 시각, 취소 시각, 변경 전후 내용만 기록한다.

## 작업 범위

- 대상 종류·기간 필터 조회
- 변경 전후 값 표시
- 행위자는 '직원'/'사장님'만 표시
- 송장·정산 상세에서 해당 기록으로 이동

## 완료 기준

- [ ] 송장 취소 기록이 시각과 함께 조회된다
- [ ] 직원 이름이 어디에도 나오지 않는다
- [ ] 사장님만 접근 가능하다
