# T-079 · 재발송과 알림 자동 해제

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 이메일·알림 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-078](T-078.md) 발송 실패 감지와 알림 생성 |
| 요구사항 근거 | §20 발송 실패 처리 |
| 주요 위치 | `app/owner/emails/` |

## 목적

해결된 알림이 남아 있으면 알림 전체를 무시하게 된다. 성공 시 즉시 정리한다.

## 요구사항 근거 (설계.md 인용)

> 재발송에 성공하면 알림을 자동으로 해제한다.

## 작업 범위

- 다시 보내기 버튼과 재발송 처리
- 성공 시 관련 알림 해제(사장님·직원 양쪽)
- 재발송 이력 기록
- 연속 실패 시 안내

## 완료 기준

- [ ] 재발송 성공 후 직원 화면의 실패 알림이 사라진다
- [ ] 재발송 이력이 별도로 남는다
- [ ] 재발송도 실패하면 알림이 유지된다
