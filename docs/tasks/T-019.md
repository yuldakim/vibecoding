# T-019 · 공장 정보 설정 화면

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 1. 마스터 데이터 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-005](T-005.md) 마이그레이션: 공장 정보·직원 계정, [T-018](T-018.md) 역할별 네비게이션과 라우트 가드 |
| 요구사항 근거 | §23 공장 정보 |
| 주요 위치 | `app/owner/settings/factory/` |

## 목적

송장 출력물과 정산 엑셀 머리말에 들어갈 정보를 한 곳에서 관리한다.

## 요구사항 근거 (설계.md 인용)

> 종이 송장과 정산 엑셀에 표시할 공장 정보: 공장명, 대표자명, 사업자등록번호, 주소, 전화번호
>
> 사장님 설정 화면에서 수정할 수 있다.

## 작업 범위

- 5개 항목 입력 폼과 저장
- 사업자등록번호 형식 검증과 자동 하이픈
- 저장 시 audit_logs 기록
- 송장·엑셀에서 이 값을 읽는 헬퍼

## 완료 기준

- [ ] 값을 바꾸면 송장 미리보기에 즉시 반영된다
- [ ] 잘못된 사업자등록번호 형식이 저장되지 않는다
- [ ] 실제 공장 정보가 입력돼 있다
