## 목적

원청과 금액이 어긋났을 때 언제 무엇이 바뀌었는지 근거를 댈 수 있어야 한다.

## 요구사항 근거 (설계.md 인용)

> 수정 전 단가, 수정 후 단가, 수정 시각은 내부 기록에 남긴다.

## 작업 범위

- 단가 변경 시 이력 자동 기록
- 원청·품목·기간 필터 조회 화면
- 기본 단가/예외 단가 구분 표시
- 사장님 전용 접근

## 완료 기준

- [ ] 단가를 바꾸면 이력이 한 건 쌓인다
- [ ] 이력에서 변경 전후 값이 모두 보인다
- [ ] 직원은 이 화면에 접근할 수 없다
