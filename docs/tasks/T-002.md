# T-002 · Next.js 프로젝트 초기화

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 0. 기반 구축 |
| 분류 | 인프라·배포 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | 없음 |
| 요구사항 근거 | §1 프로젝트 목적 |
| 주요 위치 | `app/, package.json, tsconfig.json` |

## 목적

이후 모든 화면 작업이 올라갈 뼈대를 만든다. 50대 후반 사용자를 위한 큰 글씨·큰 버튼을 기본값으로 잡을 수 있도록 Tailwind 설정까지 이 단계에서 끝낸다.

## 작업 범위

- create-next-app으로 App Router + TypeScript 프로젝트 생성
- Tailwind CSS 설치 및 기본 폰트/기본 글씨 크기 상향
- app/layout.tsx에 한국어 로케일·메타데이터 설정
- ESLint·Prettier 설정과 npm 스크립트 정리
- README에 개발 서버 실행법 기록
- package.json scripts에 `"backlog": "node tools/backlog.mjs"` 등록 (백로그 CLI는 이미 있으나 package.json이 없어 아직 `npm run backlog`로 부를 수 없다)

## 완료 기준

- [ ] `npm run dev`로 개발 서버가 뜨고 첫 화면이 렌더된다
- [ ] `npm run lint`가 통과한다
- [ ] 기본 본문 글씨가 일반 웹사이트보다 크게(최소 18px) 설정됐다

## 주의사항

- 프로젝트 언어는 한국어 고정이므로 `<html lang="ko">`로 둔다.
