# T-023 · 원청별 정산 일정 설정

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 1. 마스터 데이터 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-022](T-022.md) 원청 등록·수정 폼 |
| 요구사항 근거 | §3 원청 관리, §16 정산 승인과 자동 발송, §22 알림 |
| 주요 위치 | `app/owner/clients/[id]/schedule/` |

## 목적

자동 발송 스케줄러와 알림 표시 시점이 모두 이 두 값에서 나온다.

## 작업 범위

- 자동 발송일(매월 N일) 선택 UI
- 확인 요청 기준일 선택 UI
- 두 날짜 관계 검증(확인 요청일이 발송일보다 앞)
- 설정값 미리보기 문장 표시

## 완료 기준

- [ ] 발송일·기준일이 저장되고 원청 목록에 표시된다
- [ ] 기준일이 발송일보다 뒤면 저장이 막힌다
- [ ] '매월 10일에 자동 발송, 5일부터 확인 요청' 형태의 안내 문장이 보인다

## 주의사항

- 말일이 없는 달(29·30·31일 설정) 처리 규칙은 T-075에서 구현한다. 여기서는 안내 문구로 알린다.
