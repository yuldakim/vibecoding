> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 주요 위치 | `app/invoices/new/` |

## 목적

직원이 송장을 쓰다가 새 품목을 만나면 작업이 끊긴다. 그 자리에서 추가하고 이어서 쓰게 한다.

## 요구사항 근거 (설계.md 인용)

> 송장 작성 중 새 품목 바로 추가

## 작업 범위

- 검색 결과 없음 상태에서 '이 이름으로 품목 추가' 버튼
- 작성 중인 송장 내용 유지한 채 모달로 추가
- 추가 즉시 해당 줄에 반영
- 중복 이름 경고

## 완료 기준

- [ ] 품목 추가 후 작성 중이던 줄과 수량이 그대로 남는다
- [ ] 추가된 품목이 원청 품목 목록에 등록된다
- [ ] 직원 권한으로도 추가할 수 있다

## 주의사항

- 직원 권한에 '품목 추가'가 명시돼 있지 않지만 송장 작성 흐름상 필요하다. 사장님에게 확인 후 확정한다.
