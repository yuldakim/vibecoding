# T-062 · 정산 상세 표 화면

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 4. 월말 정산 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-060](T-060.md) 정산 금액 계산 로직, [T-061](T-061.md) 월별 정산 목록 화면, [T-016](T-016.md) RLS·서버 권한 경계 구현 |
| 요구사항 근거 | §15 정산 화면 |
| 주요 위치 | `app/owner/settlements/[id]/` |

## 목적

사장님이 엑셀을 열지 않고 사이트에서 검토하고 승인까지 끝내게 하는 것이 이 화면의 목적이다.

## 요구사항 근거 (설계.md 인용)

> 사장님은 엑셀을 먼저 내려받지 않아도 사이트에서 정산 내역 전체를 표로 확인할 수 있어야 한다.
>
> 표에 표시할 내용: 납품일, 송장번호, 품목명, 사이즈, 수량, 적용 단가, 공급가액, 품목별 비고, 이월 여부

## 작업 범위

- 9개 열 전체 표시
- 합계 영역(전체 공급가액·부가세·최종 합계) 고정 표시
- 미정 단가 줄 강조
- 긴 내역의 스크롤·고정 헤더
- 사장님 전용 접근 확인

## 완료 기준

- [ ] 요구사항의 9개 열이 모두 있다
- [ ] 합계가 항상 보인다
- [ ] 직원 세션으로는 접근이 차단된다
