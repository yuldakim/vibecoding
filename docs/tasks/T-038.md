# T-038 · 송장 줄: 비고 입력과 줄 분리 규칙

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-037](T-037.md) 송장 줄: 사이즈 선택·수량 입력 |
| 요구사항 근거 | §6 송장 작성 |
| 주요 위치 | `app/invoices/new/` |

## 목적

비고는 예외 단가의 근거이자 원청과의 소통 수단이다. 자동 병합으로 비고가 사라지면 정산 근거가 사라진다.

## 요구사항 근거 (설계.md 인용)

> 같은 품목과 같은 사이즈라도 비고가 다르면 별도 줄로 유지한다.

## 작업 범위

- 줄별 비고 입력 필드
- 같은 품목·사이즈·같은 비고일 때의 처리 규칙 확정(병합 또는 유지)
- 비고 길이 제한과 인쇄 시 줄바꿈 고려
- 비고가 있는 줄 시각적 표시

## 완료 기준

- [ ] 같은 품목·사이즈·다른 비고가 두 줄로 저장된다
- [ ] 비고가 인쇄물에서 잘리지 않는다
- [ ] 비고 없이도 저장된다
