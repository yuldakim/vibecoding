## 목적

공장에서 두 사람이 동시에 확정하는 상황은 실제로 일어난다. 번호 중복은 정산 근거를 무너뜨린다.

## 요구사항 근거 (설계.md 인용)

> 송장번호는 원청이나 연도와 관계없이 계속 이어지는 일련번호를 사용한다.
>
> 취소된 번호는 다시 사용하지 않는다.

## 작업 범위

- 동시 확정 요청 N개 발사 테스트
- 번호 중복 없음 검증
- 취소 후 다음 번호가 감소하지 않음 검증
- 확정 중복 클릭 시 송장 1건만 생성 검증

## 완료 기준

- [ ] 동시 요청 20건에서 번호가 모두 유일하다
- [ ] 취소 후 번호가 이어진다
- [ ] 중복 클릭으로 송장이 두 개 생기지 않는다
