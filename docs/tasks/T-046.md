# T-046 · 인쇄 다중 페이지 처리

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 엑셀·출력 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-045](T-045.md) 송장 인쇄 레이아웃(A4 상하 2부) |
| 요구사항 근거 | §8 출력 형식 |
| 주요 위치 | `app/invoices/[id]/print/` |

## 목적

20줄까지 들어가는 송장이 한 장에 안 담길 때도 상하 2부 구조와 페이지 표기를 유지해야 한다.

## 요구사항 근거 (설계.md 인용)

> 품목이 많으면 여러 페이지로 출력한다.
>
> 각 A4 페이지에 위·아래 동일한 송장을 배치한다.

## 작업 범위

- 한 부에 들어갈 최대 줄 수 계산
- 페이지 분할과 페이지별 상하 2부 배치
- '1/2' 형식 페이지 번호
- 페이지마다 머리말(원청·송장번호) 반복

## 완료 기준

- [ ] 20줄 송장이 페이지 번호와 함께 여러 장으로 출력된다
- [ ] 각 페이지가 상하 2부 구조를 유지한다
- [ ] 줄이 페이지 경계에서 잘리지 않는다
