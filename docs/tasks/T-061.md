> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 4. 월말 정산 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-059](T-059.md) 월말 정산 내역 자동 생성, [T-018](T-018.md) 역할별 네비게이션과 라우트 가드 |
| 요구사항 근거 | §25 월별 정산 목록 |
| 주요 위치 | `app/owner/settlements/` |

## 목적

사장님이 '이번 달 어디까지 됐지'를 묻는 화면이다. 상태와 남은 일이 바로 보여야 한다.

## 작업 범위

- 연월 선택과 원청별 행 표시
- 상태 배지(작성중·미정 있음·확인 필요·승인됨·발송됨·다시 확인 필요)
- 발송 예정일과 경과 여부 표시
- 행 클릭 시 상세 진입

## 완료 기준

- [ ] 한 화면에서 모든 원청의 진행 상태가 보인다
- [ ] 발송일이 지난 건이 눈에 띈다
- [ ] 미정 단가가 있는 원청이 표시된다
