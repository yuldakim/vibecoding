# T-064 · 정산 진입 시 미정 단가 점검

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 4. 월말 정산 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-054](T-054.md) 단가 미정 목록, [T-062](T-062.md) 정산 상세 표 화면 |
| 요구사항 근거 | §12 단가 미정 처리, §16 정산 승인 흐름 |
| 주요 위치 | `app/owner/settlements/[id]/` |

## 목적

미정 단가가 있는 채로 승인·발송되는 사고를 막는다.

## 요구사항 근거 (설계.md 인용)

> 월말 정산 내역 자동 생성 → 단가 미정 여부 확인 → 사장님이 단가 입력 → 최종 정산서 완성

## 작업 범위

- 상세 상단에 미정 건수 배너
- 미정 줄로 바로 이동
- 단가 확인 요청서 만들기 버튼 연결
- 미정이 남아 있으면 최종 승인 버튼 비활성화

## 완료 기준

- [ ] 미정이 1건이라도 있으면 승인이 막힌다
- [ ] 배너에서 단가 확인 요청 화면으로 이동한다
- [ ] 미정이 0건이 되면 승인 버튼이 활성화된다
