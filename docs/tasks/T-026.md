## 목적

한 원청에 100개 이상 품목이 쌓이므로 목록 자체가 검색과 정렬을 갖춰야 쓸 수 있다.

## 요구사항 근거 (설계.md 인용)

> 품목은 원청별로 따로 관리한다. 한 원청에 50~100개 이상의 품목이 등록될 수 있다.

## 작업 범위

- 원청 선택 후 품목 목록 표시
- 품목명 검색 입력
- 숨김 품목 포함/제외 토글
- 즐겨찾기·최근 사용 표시

## 완료 기준

- [ ] 품목 100개에서 검색이 즉각 반응한다
- [ ] 숨김 품목이 기본 목록에서 빠진다
- [ ] 다른 원청의 품목이 섞이지 않는다
