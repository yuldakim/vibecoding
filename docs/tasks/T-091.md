## 목적

주 사용자가 50대 후반이라는 제약이 실제로 지켜졌는지는 기기에서 봐야 안다.

## 요구사항 근거 (설계.md 인용)

> 컴퓨터, 태블릿, 휴대폰에서 모두 사용할 수 있어야 하며, 글씨와 버튼을 크게 하고 복잡한 메뉴와 전문 용어를 최소화한다.

## 작업 범위

- 주요 화면 12개를 3개 폭에서 확인
- 터치 영역 44px·버튼 높이 기준 점검
- 색 대비 WCAG AA 확인
- 전문 용어 사용 여부 문구 점검
- 발견 사항 수정 목록화

## 완료 기준

- [ ] 3개 폭 모두에서 가로 스크롤이 생기지 않는다
- [ ] 본문 대비가 AA를 만족한다
- [ ] 발견된 문제가 목록으로 정리됐다
