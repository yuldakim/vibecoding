# T-050 · 송장 취소 처리

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-044](T-044.md) 송장 확정과 번호 부여, [T-012](T-012.md) 마이그레이션: 변경 기록·발송 이력·알림 |
| 요구사항 근거 | §8 출력 후 수정 |
| 주요 위치 | `app/invoices/[id]/cancel/` |

## 목적

출력한 송장은 고칠 수 없으므로 취소 후 새로 쓰는 것이 유일한 정정 방법이다. 취소된 송장은 정산에 절대 들어가면 안 된다.

## 요구사항 근거 (설계.md 인용)

> 기존 송장을 `취소` 처리
>
> 취소된 송장은 월말 정산에서 제외
>
> 취소된 번호는 다시 사용하지 않는다.

## 작업 범위

- 취소 확인 절차(되돌릴 수 없음 경고)
- 상태 cancelled 전이와 취소 시각 기록
- 정산 생성 쿼리에서 취소 송장 제외
- 이미 정산에 포함된 송장 취소 시 처리 규칙 정의

## 완료 기준

- [ ] 취소된 송장이 새 정산 내역에 포함되지 않는다
- [ ] 취소 후 번호가 재사용되지 않는다
- [ ] 취소 시각이 기록된다

## 주의사항

- 이미 발송된 정산서에 포함된 송장을 취소하면 수정 정산서(T-080) 대상이 된다. 그 경로로 안내한다.
