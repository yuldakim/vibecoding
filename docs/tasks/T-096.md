# T-096 · 기존 정산 엑셀 양식 확보·분석

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 문서·운영 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | 없음 |
| 요구사항 근거 | §18 최종 정산 엑셀 |

## 목적

설계에 '기존 엑셀 양식의 필수 내용을 유지하되 더 보기 쉽게 개선한다'고 돼 있으므로 원본을 보지 않고는 만들 수 없다. 원청이 이미 익숙한 형식을 깨지 않기 위해서도 필요하다.

## 요구사항 근거 (설계.md 인용)

> 기존에 사용하던 엑셀 양식의 필수 내용을 유지하되 더 보기 쉽게 개선한다.

## 작업 범위

- 실제 사용 중인 정산 엑셀 파일 수령
- 열 구성·서식·머리말 분석
- 원청이 반드시 요구하는 항목과 개선 가능한 항목 구분
- 개선안 스케치 후 사장님 확인

## 완료 기준

- [ ] 실제 엑셀 파일을 확인했다
- [ ] 필수 유지 항목 목록이 정리됐다
- [ ] 개선안에 사장님 동의를 받았다

## 사람이 결정해야 할 것

- 기존 양식 중 반드시 유지해야 할 항목
- 원청마다 양식이 다른지 여부
- 개선 폭(열 순서 변경·서식 변경 허용 범위)
