# T-073 · 이메일 발송 인프라 구축

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 이메일·알림 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-001](T-001.md) 프로젝트 기본 정보·운영 계정 확정 |
| 요구사항 근거 | §19 이메일 발송 |
| 주요 위치 | `lib/email/` |

## 목적

단가 확인 요청·정산서·수정 정산서가 모두 이 계층을 통해 나간다. 실패를 정확히 감지하는 것이 핵심이다.

## 요구사항 근거 (설계.md 인용)

> 사이트 전용 이메일 주소를 새로 만들어 사용한다.
>
> 사이트 전용 이메일로 발송할 내용: 단가 확인 요청 엑셀, 최종 정산 엑셀, 수정 정산 엑셀

## 작업 범위

- 발송 서비스 선정과 연동(발신 도메인 인증 포함)
- 첨부 파일(엑셀) 전송 지원
- 발송 결과 성공·실패 판정과 실패 사유 보존
- 발송 이력 기록
- 테스트 발송 경로

## 완료 기준

- [ ] 실제 주소로 엑셀이 첨부된 메일이 도착한다
- [ ] 잘못된 수신 주소에서 실패가 감지되고 사유가 남는다
- [ ] 발신 주소가 스팸으로 분류되지 않도록 도메인 인증이 설정됐다

## 주의사항

- API 키는 환경변수로만 다룬다. 정산서에는 금액이 들어가므로 수신 주소 오타가 정보 유출로 이어질 수 있다.
