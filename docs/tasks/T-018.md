| 단계 | 0. 기반 구축 |
| 분류 | 인증·권한 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-013](T-013.md) 직원 로그인(계정 선택 방식), [T-014](T-014.md) 사장님 모드 비밀번호 인증, [T-016](T-016.md) RLS·서버 권한 경계 구현, [T-017](T-017.md) 공통 UI 기반(큰 글씨·큰 버튼·반응형) |

## 목적

메뉴를 역할별로 줄여 '복잡한 메뉴 최소화' 요구를 만족시키고, 주소를 직접 입력해도 사장님 화면에 못 들어가게 한다.

## 작업 범위

- 직원 메뉴(송장 중심 4~5개)와 사장님 메뉴 구성
- 미들웨어에서 /owner 경로 역할 검사
- 권한 없는 접근 시 사장님 모드 입력 화면으로 유도
- 현재 역할 표시와 역할 전환 버튼

## 완료 기준

- [ ] 직원 세션으로 /owner 경로에 접근하면 차단된다
- [ ] 직원 메뉴에 정산·단가 항목이 보이지 않는다
- [ ] 역할 전환이 2번 이내 조작으로 된다
