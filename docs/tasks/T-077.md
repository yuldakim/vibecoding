> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 기능 구현 |
| 우선순위 | P2 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-073](T-073.md) 이메일 발송 인프라 구축 |
| 요구사항 근거 | §25 발송 내역 |
| 주요 위치 | `app/owner/emails/` |

## 목적

'보냈나 안 보냈나'를 확인하는 화면이다. 실패 건과 수정본도 함께 보여야 한다.

## 작업 범위

- 발송 이력 목록(원청·종류·파일명·시각·결과)
- 기간·원청·종류 필터
- 실패 건 강조와 재발송 진입
- 첨부 파일 다시 받기

## 완료 기준

- [ ] 단가 확인 요청·정산서·수정 정산서가 종류별로 구분된다
- [ ] 실패 건이 눈에 띈다
- [ ] 과거에 보낸 파일을 다시 받을 수 있다
