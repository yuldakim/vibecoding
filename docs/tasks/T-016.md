# T-016 · RLS·서버 권한 경계 구현

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 0. 기반 구축 |
| 분류 | 인증·권한 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-010](T-010.md) 마이그레이션: 월별 봉제 단가, [T-011](T-011.md) 마이그레이션: 정산서·정산 내역, [T-013](T-013.md) 직원 로그인(계정 선택 방식), [T-014](T-014.md) 사장님 모드 비밀번호 인증 |
| 요구사항 근거 | §2 직원에게 숨기는 정보, §26 직원의 단가 및 정산 금액 열람 제외 |
| 주요 위치 | `supabase/migrations/, lib/auth/` |

## 목적

화면에서 감추는 것만으로는 부족하다. 직원 세션으로 API를 직접 호출해도 단가·공급가액·정산 총액이 나오지 않아야 한다.

## 요구사항 근거 (설계.md 인용)

> 직원에게 숨기는 정보: 봉제 단가, 공급가액, 부가세, 정산 총금액, 정산서 상세 내용

## 작업 범위

- monthly_prices·settlements·settlement_lines에 역할 기반 접근 제한
- 서버 액션·라우트 핸들러 공통 역할 검사 헬퍼
- 직원 응답 DTO에서 금액 필드 제거
- 권한 위반 시 403 처리와 화면 안내

## 완료 기준

- [ ] 직원 세션으로 단가 조회 API를 호출하면 403 또는 빈 결과가 온다
- [ ] 직원 화면 응답 페이로드에 금액 필드가 전혀 없다
- [ ] 사장님 세션에서는 정상 동작한다

## 주의사항

- 네트워크 탭에 금액이 실려 오면 실패다. 화면 숨김이 아니라 응답에서 빼야 한다.
