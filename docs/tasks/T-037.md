# T-037 · 송장 줄: 사이즈 선택·수량 입력

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-036](T-036.md) 송장 작성 2단계: 품목 줄 입력 UI, [T-034](T-034.md) 사이즈 관리(기본 4종 + 직접 입력) |
| 요구사항 근거 | §5 사이즈 관리, §6 송장 작성 |
| 주요 위치 | `app/invoices/new/` |

## 목적

수량은 오입력이 곧 오납품·오정산이 된다. 큰 숫자 입력과 즉각적인 합계 표시로 실수를 줄인다.

## 작업 범위

- 줄별 사이즈 선택(기본 4종 + 직접 입력)
- 수량 입력(숫자 키패드 친화, 0·음수 차단)
- 전체 납품 수량 실시간 합계 표시
- 품목마다 사이즈를 제한하지 않음

## 완료 기준

- [ ] 수량 0이나 음수가 저장되지 않는다
- [ ] 전체 수량 합계가 줄 변경 즉시 갱신된다
- [ ] 모든 품목에서 모든 사이즈를 고를 수 있다
