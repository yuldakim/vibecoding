| 분류 | 엑셀·출력 |

## 목적

원청에 실제로 전달되는 최종 산출물이다. 금액이 정확해야 하고 기존 양식에 익숙한 담당자가 바로 읽을 수 있어야 한다.

## 요구사항 근거 (설계.md 인용)

> 엑셀에 포함할 내용: 공장 정보, 원청 정보, 정산 대상 월, 납품일, 송장번호, 최종 품목명, 사이즈, 수량, 단가, 공급가액, 품목별 비고, 전월 이월 표시, 전체 공급가액, 부가세, 최종 합계

## 작업 범위

- 머리말 영역(공장 정보·원청 정보·정산 대상 월)
- 내역 표 9개 열과 전월 이월 표시
- 합계 영역 3행(전체 공급가액·부가세·최종 합계)
- 금액 천 단위 서식과 열 너비
- 파일명 규칙: `A원청_2026년07월_정산서.xlsx`

## 완료 기준

- [ ] 요구된 15개 항목이 모두 들어간다
- [ ] 엑셀 합계가 사이트 화면 합계와 정확히 일치한다
- [ ] 파일명이 규칙대로 생성된다
