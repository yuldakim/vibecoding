# T-010 · 마이그레이션: 월별 봉제 단가

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 0. 기반 구축 |
| 분류 | 데이터 모델 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-004](T-004.md) 전체 DB 스키마 설계 확정, [T-007](T-007.md) 마이그레이션: 품목·품목 이력, [T-008](T-008.md) 마이그레이션: 사이즈 |
| 요구사항 근거 | §10 월별 봉제 단가, §12 단가 미정 처리 |
| 주요 위치 | `supabase/migrations/` |

## 목적

단가는 정산 금액의 근거다. 같은 조합에서 월별로 단 하나의 기본 단가만 존재하도록 강제해야 정산이 흔들리지 않는다.

## 요구사항 근거 (설계.md 인용)

> 같은 원청, 품목, 사이즈, 적용 월에서는 기본 단가가 동일하다.
>
> 단가는 부가세가 포함되지 않은 공급가액 기준이다.

## 작업 범위

- monthly_prices 테이블(원청, 품목, 사이즈, 적용 연월, 단가, 미정 여부)
- (원청, 품목, 사이즈, 적용 연월) 유니크 제약
- 단가 변경 이력 테이블(변경 전·후·시각)
- 단가는 정수(원), 공급가액 기준임을 컬럼 주석에 명시

## 완료 기준

- [ ] 같은 조합의 중복 단가가 저장되지 않는다
- [ ] 미정 상태가 단가 null과 구분되거나 동일 규칙으로 명확히 정의됐다
- [ ] 단가 수정 시 이력이 남는 구조다

## 주의사항

- 예외 단가는 여기가 아니라 송장 줄/정산 내역에 따로 저장한다(T-057).
