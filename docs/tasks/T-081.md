# T-081 · 발송본과 수정본 변경 내역 자동 비교

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 엑셀·출력 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-080](T-080.md) 수정 정산서 생성 |
| 요구사항 근거 | §21 발송 완료 후 수정 정산서 |
| 주요 위치 | `lib/settlements/diff.ts` |

## 목적

원청에 '무엇이 왜 바뀌었는지'를 설명해야 한다. 사람이 손으로 적으면 빠뜨린다.

## 요구사항 근거 (설계.md 인용)

> 시스템은 기존 발송본과 수정본을 비교하여 변경 내역을 자동 작성한다.
>
> 송장번호 001253: 수량 20장 → 25장 / 특정 품목 단가: 3,500원 → 3,700원 / 공급가액: 1,000,000원 → 1,025,000원

## 작업 범위

- 줄 단위 비교(추가·삭제·수량·단가·비고 변경)
- 합계 변경 비교
- 예시와 같은 형식의 변경 문장 생성
- 변경 없음 판정

## 완료 기준

- [ ] 수량·단가 변경이 '20장 → 25장' 형식으로 나온다
- [ ] 줄 추가·삭제가 빠짐없이 잡힌다
- [ ] 합계 변경이 함께 표시된다
