# T-067 · 정산 최종 승인

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 4. 월말 정산 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-062](T-062.md) 정산 상세 표 화면, [T-064](T-064.md) 정산 진입 시 미정 단가 점검 |
| 요구사항 근거 | §16 정산 승인과 자동 발송 |
| 주요 위치 | `app/owner/settlements/[id]/approve/` |

## 목적

승인하지 않은 정산서는 발송일이 되어도 나가지 않는다. 승인이 발송의 유일한 조건이다.

## 요구사항 근거 (설계.md 인용)

> 승인된 정산서만 원청별 발송 예정일에 자동 발송
>
> 발송일 전에 승인하지 않았다면 발송하지 않는다.

## 작업 범위

- 최종 승인 버튼과 확인 절차
- 승인 시각·승인 상태 저장
- 미정 단가 있으면 승인 차단
- 승인 후 화면 상태 변경(발송 대기)
- 승인 취소(발송 전) 허용

## 완료 기준

- [ ] 승인하면 상태가 '승인됨'으로 바뀌고 시각이 남는다
- [ ] 미정 단가가 있으면 승인되지 않는다
- [ ] 승인 전에는 자동 발송 대상에 포함되지 않는다
