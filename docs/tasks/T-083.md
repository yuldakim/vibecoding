# T-083 · 알림 생성 규칙 구현

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 6. 알림·화면·마무리 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-012](T-012.md) 마이그레이션: 변경 기록·발송 이력·알림 |
| 요구사항 근거 | §22 알림 |
| 주요 위치 | `lib/notifications/rules.ts` |

## 목적

알림이 안 뜨거나 안 사라지면 사이트 전체의 신뢰가 깨진다. 생성·해제 조건을 한 곳에 모아 관리한다.

## 작업 범위

- 사장님 알림 7종 생성 조건 정의
- 직원 알림 3종 생성 조건 정의
- 해제 조건(단가 입력 완료·승인 완료·발송 성공 등)
- 중복 알림 방지
- 알림 조회 API(역할별 필터)

## 완료 기준

- [ ] 조건이 해소되면 알림이 자동으로 사라진다
- [ ] 같은 사건으로 알림이 중복 생성되지 않는다
- [ ] 직원 알림에 금액 정보가 들어가지 않는다
