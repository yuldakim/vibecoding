## 목적

정산을 막는 유일한 요인이 미정 단가다. 무엇이 비었는지 원청별로 정확히 집계한다.

## 요구사항 근거 (설계.md 인용)

> 월말 정산을 시작했을 때 단가가 없는 품목은 원청별로 자동 정리한다.

## 작업 범위

- 원청·월 기준 미정 항목 집계 쿼리
- 품목명·사이즈·적용월·납품일·송장번호·수량 표시
- 이월 송장의 실제 납품월 기준 미정도 포함
- 바로 단가 입력 진입

## 완료 기준

- [ ] 송장에 있는데 단가 없는 조합이 빠짐없이 나온다
- [ ] 이월 송장의 미정도 포함된다
- [ ] 목록에서 바로 단가를 넣을 수 있다
