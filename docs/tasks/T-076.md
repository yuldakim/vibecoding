# T-076 · 발송일 경과 후 '지금 발송'

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 이메일·알림 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-075](T-075.md) 정산서 자동 발송 스케줄러 |
| 요구사항 근거 | §16 정산 승인과 자동 발송 |
| 주요 위치 | `app/owner/settlements/[id]/` |

## 목적

뒤늦게 승인했다고 예고 없이 메일이 나가면 사장님이 통제력을 잃는다. 이 경우는 반드시 사람이 누르게 한다.

## 요구사항 근거 (설계.md 인용)

> 발송일이 지난 후 승인한 경우 자동 발송하지 않고 `지금 발송` 버튼을 보여준다. 사장님이 버튼을 눌러야 발송된다.

## 작업 범위

- 발송일 경과 + 승인됨 상태 판정
- '지금 발송' 버튼 노출과 발송 처리
- 경과 알림 표시
- 발송 후 상태 전이

## 완료 기준

- [ ] 발송일 지난 뒤 승인해도 자동으로 나가지 않는다
- [ ] 지금 발송 버튼이 보이고 동작한다
- [ ] 발송 후 버튼이 사라진다
