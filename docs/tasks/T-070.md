# T-070 · 단가 확인 요청 미리보기와 수동 발송

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 이메일·알림 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-069](T-069.md) 단가 확인 요청 엑셀 생성, [T-074](T-074.md) 이메일 문구 치환과 발송 전 편집 |
| 요구사항 근거 | §12 단가 미정 처리, §25 단가 확인 요청서 미리보기 |
| 주요 위치 | `app/owner/prices/request/` |

## 목적

자동 발송은 명시적으로 금지돼 있다. 사장님 확인을 발송의 필수 조건으로 만든다.

## 요구사항 근거 (설계.md 인용)

> 사장님이 내용을 확인한 뒤 `단가 확인 요청 보내기` 버튼을 눌러야 이메일이 발송된다. 자동으로 발송하지 않는다.

## 작업 범위

- 미정 항목 미리보기 표
- 첨부될 엑셀 다운로드 미리보기
- 이메일 제목·본문 확인·수정
- '단가 확인 요청 보내기' 버튼과 발송
- 발송 이력 기록

## 완료 기준

- [ ] 버튼을 누르기 전에는 메일이 나가지 않는다
- [ ] 미리보기 내용과 실제 첨부 파일이 같다
- [ ] 발송 후 이력에 남는다

## 주의사항

- 원청의 회신을 자동 수집하거나 분석하는 기능은 1차 범위 제외다.
