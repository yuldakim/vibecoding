# T-047 · 인쇄 실행과 출력 시각 기록

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-045](T-045.md) 송장 인쇄 레이아웃(A4 상하 2부), [T-012](T-012.md) 마이그레이션: 변경 기록·발송 이력·알림 |
| 요구사항 근거 | §8 출력과 취소, §25 송장 인쇄 |
| 주요 위치 | `app/invoices/[id]/print/` |

## 목적

재출력해도 인쇄물은 최초와 완전히 같아야 하고, 몇 번 뽑았는지는 내부에만 남는다.

## 요구사항 근거 (설계.md 인용)

> 재출력은 최초 출력물과 완전히 동일하게 출력한다. `재출력` 문구를 표시하지 않는다.
>
> 내부에는 작성 시각, 출력 시각, 재출력 시각, 취소 시각, 변경 전후 내용만 기록한다.

## 작업 범위

- 인쇄 버튼과 window.print 호출
- 최초 출력 시각·재출력 시각 기록
- 재출력물에 '재출력' 표기가 없음을 확인
- 인쇄 후 다음 행동 안내(목록으로/새 송장)

## 완료 기준

- [ ] 재출력물과 최초 출력물이 픽셀 단위로 같다
- [ ] 출력·재출력 시각이 audit_logs에 남는다
- [ ] 인쇄 취소해도 오류가 나지 않는다
