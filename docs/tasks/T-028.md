# T-028 · 품목 검색(이전 이름 포함)

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 1. 마스터 데이터 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-007](T-007.md) 마이그레이션: 품목·품목 이력, [T-026](T-026.md) 원청별 품목 목록 화면 |
| 요구사항 근거 | §4 품목명 변경 규칙 |
| 주요 위치 | `lib/items/search.ts` |

## 목적

이름이 바뀐 품목을 사장님이 옛 이름으로 기억하고 있거나 반대인 경우에도 찾을 수 있어야 한다.

## 요구사항 근거 (설계.md 인용)

> 사이트 검색에서는 새 이름으로 검색해도 이전 이름으로 작성된 송장이 함께 조회되어야 한다.

## 작업 범위

- items + item_aliases 통합 검색 쿼리
- 합쳐진 품목까지 따라가는 최종 품목 해석
- 한글 부분 일치 검색과 인덱스
- 검색 결과에 '이전 이름: ○○' 표시

## 완료 기준

- [ ] 새 이름으로 검색하면 옛 이름 송장이 함께 나온다
- [ ] 옛 이름으로 검색해도 현재 품목이 나온다
- [ ] 합쳐진 품목이 최종 품목으로 묶여 나온다
