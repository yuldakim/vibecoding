# T-040 · 납품 날짜 선택

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-036](T-036.md) 송장 작성 2단계: 품목 줄 입력 UI |
| 요구사항 근거 | §6 납품 날짜 |
| 주요 위치 | `app/invoices/new/` |

## 목적

납품 날짜가 정산 월을 결정한다. 기본값은 편하게, 변경은 명확하게 만든다.

## 요구사항 근거 (설계.md 인용)

> 기본값은 오늘 날짜다. 직원이 이전 날짜나 다른 날짜로 직접 변경할 수 있다.

## 작업 범위

- 기본값 오늘로 설정
- 큰 달력 선택 UI
- 오늘이 아닌 날짜 선택 시 강조 표시
- 지난달 날짜 선택 시 이월 가능성 안내

## 완료 기준

- [ ] 새 송장을 열면 오늘 날짜가 들어있다
- [ ] 지난 날짜로 변경이 가능하다
- [ ] 지난달 날짜를 고르면 이월될 수 있다는 안내가 뜬다

## 주의사항

- 미래 날짜 허용 여부는 설계에 없다. 허용하되 경고를 띄우는 쪽으로 둔다.
