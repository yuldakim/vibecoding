# T-063 · 정산 화면 단가 수정과 실시간 재계산

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 4. 월말 정산 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-062](T-062.md) 정산 상세 표 화면, [T-057](T-057.md) 송장 줄 예외 단가, [T-060](T-060.md) 정산 금액 계산 로직 |
| 요구사항 근거 | §15 정산 화면 |
| 주요 위치 | `app/owner/settlements/[id]/` |

## 목적

사장님이 수정 결과를 바로 확인하고 승인 여부를 판단하게 한다.

## 요구사항 근거 (설계.md 인용)

> 사장님은 사이트에서 단가를 수정하고 최종 금액이 자동으로 다시 계산되는 것을 확인한다.

## 작업 범위

- 줄 단가 수정 시 해당 줄 공급가액 갱신
- 전체 합계·부가세 재계산
- 저장 상태 표시(저장 중·저장됨)
- 승인된 정산서 수정 시 승인 해제 연계(T-068)

## 완료 기준

- [ ] 단가를 고치면 합계가 즉시 바뀐다
- [ ] 새로고침해도 수정값이 유지된다
- [ ] 승인 상태였다면 '다시 확인 필요'로 바뀐다
