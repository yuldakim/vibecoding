# T-020 · 직원 계정 관리 화면

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 1. 마스터 데이터 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-005](T-005.md) 마이그레이션: 공장 정보·직원 계정, [T-018](T-018.md) 역할별 네비게이션과 라우트 가드 |
| 요구사항 근거 | §2 사장님 권한, §24 데이터 보존 원칙 |
| 주요 위치 | `app/owner/settings/staff/` |

## 목적

직원이 바뀌어도 사장님이 개발자 없이 계정을 관리하게 한다. 계정은 삭제하지 않고 사용 중지한다.

## 요구사항 근거 (설계.md 인용)

> 사장님이 직원용 계정을 여러 개 생성할 수 있다.
>
> 삭제 대신 `숨김`, `사용 중지`, `취소` 상태를 사용한다.

## 작업 범위

- 계정 목록(활성/중지 구분)
- 이름만으로 계정 추가
- 사용 중지·재사용 토글
- 중지된 계정이 로그인 화면에서 사라지는지 확인

## 완료 기준

- [ ] 계정을 추가하면 로그인 화면에 바로 나타난다
- [ ] 중지해도 계정 행이 DB에 남는다
- [ ] 삭제 버튼이 존재하지 않는다
