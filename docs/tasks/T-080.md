# T-080 · 수정 정산서 생성

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 엑셀·출력 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-071](T-071.md) 최종 정산 엑셀 생성, [T-068](T-068.md) 승인 후 수정 시 승인 자동 취소 |
| 요구사항 근거 | §21 발송 완료 후 수정 정산서 |
| 주요 위치 | `lib/settlements/revision.ts` |

## 목적

발송본은 원청이 이미 갖고 있으므로 증거로 보존해야 한다. 정정은 항상 새 파일로 한다.

## 요구사항 근거 (설계.md 인용)

> 이미 발송한 정산서는 수정하거나 덮어쓰지 않는다.
>
> 최초 파일: `A원청_2026년07월_정산서.xlsx` / 수정 파일: `A원청_2026년07월_정산서_수정1.xlsx`

## 작업 범위

- 발송본 스냅샷 보존 확인
- 수정본 생성(회차 증가)과 내역 수정 허용
- 파일명 `_수정N` 규칙
- 수정본도 승인 절차를 다시 거치도록 연결

## 완료 기준

- [ ] 최초 발송본이 그대로 남아 있다
- [ ] 수정본 파일명에 회차가 붙는다
- [ ] 수정본이 승인 없이 발송되지 않는다
