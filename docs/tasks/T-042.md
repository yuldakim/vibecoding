# T-042 · 임시 송장 목록 화면

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-041](T-041.md) 임시 저장 |
| 요구사항 근거 | §7 임시 저장과 확정, §25 임시 송장 목록 |
| 주요 위치 | `app/invoices/drafts/` |

## 목적

임시 송장이 쌓여 방치되면 혼란을 부른다. 목록에서 원청·날짜·수정 시각을 보고 정리하게 한다.

## 작업 범위

- 임시 송장 목록(원청·납품일·품목 수·마지막 수정)
- 이어서 작성 진입
- 삭제(확인 포함)
- 오래된 임시 송장 표시

## 완료 기준

- [ ] 목록에서 바로 이어서 작성된다
- [ ] 삭제한 임시 송장이 목록에서 사라진다
- [ ] 확정된 송장은 이 목록에 없다
