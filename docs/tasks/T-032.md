# T-032 · 품목명 변경(이력 보존)

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 1. 마스터 데이터 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-007](T-007.md) 마이그레이션: 품목·품목 이력, [T-027](T-027.md) 품목 추가·수정 |
| 요구사항 근거 | §4 품목명 변경 규칙, §25 품목명 변경·합치기 |
| 주요 위치 | `app/owner/items/rename/` |

## 목적

원청이 품목명을 바꿔도 이미 출력된 종이 송장과 사이트 기록이 어긋나면 안 된다. 이름 변경은 과거를 건드리지 않는 연산이어야 한다.

## 요구사항 근거 (설계.md 인용)

> 품목 이름을 변경하거나 합쳐도 기존 송장에는 당시 사용한 이름을 그대로 보존한다.
>
> 월말 정산서에는 연결된 이전 품목들을 합쳐서 최종 품목명만 표시한다.

## 작업 범위

- 이름 변경 화면과 변경 전후 미리보기
- item_aliases에 이전 이름 기록
- 기존 송장 줄의 품목명 스냅샷은 변경하지 않음 확인
- 변경 영향 안내('과거 송장 표시는 그대로, 정산서는 새 이름')

## 완료 기준

- [x] 변경 후에도 과거 송장 상세에 옛 이름이 보인다 — 송장 상세 화면 자체는 아직 없어(추후 T-048 등) 직접은 못 봤다. 실제 DB에 가짜 `invoices`+`invoice_lines`(`item_name_snapshot`)를 시딩하고 이름을 바꿔서, `renameItem`이 `invoice_lines`를 전혀 건드리지 않고 스냅샷이 그대로 남는 것을 확인. 브라우저로도 실제 성공 케이스(이름 변경 → alias 기록) 확인
- [x] 정산서에는 새 이름만 보인다 — 정산서 엑셀(T-072)이 아직 없어 직접 확인 불가. `items.name`이 실제로 새 이름으로 바뀌는 것과 `renameItem`이 `merged_into_item_id`를 건드리지 않는 것(합치기와 혼동 안 됨)을 확인. **완전한 충족은 T-072 구현 시 재확인 필요** — adversarial-reviewer 지적
- [x] 이전 이름이 검색에 걸린다 — 실제 `lib/items/search.ts`의 `searchItems`로 옛 이름 검색 시 새 이름 품목이 `matchedAlias`와 함께 반환되는 것 확인

## 주의사항

- 이 기능이 "되돌리기 어렵다"는 것의 실제 의미: 데이터 자체는 되돌릴 수 있다(B→A로 다시 바꾸면 복구됨, `item_aliases` 중복 검사가 자기 자신은 제외하므로 안 막힘, `invoice_lines` 스냅샷은 원래 안 건드리므로 무손상). 진짜 되돌리기 어려운 것은 **대외 효과**다 — 이름을 바꾼 뒤 정산서가 이미 나가면 원청은 새 이름으로 받는다. adversarial-reviewer 확인.
- 실행 전 영향 범위(해당 품목이 쓰인 송장 수)를 먼저 보여준다. **adversarial-reviewer 지적으로 수정**: 처음엔 `invoice_lines` 행 수(줄 수)를 그대로 세서, 한 송장에 같은 품목이 여러 줄 들어가면 부풀려지고 임시/취소 송장까지 포함됐다. `invoices.status='confirmed'`인 것만, `invoice_id` 기준으로 중복 제거해서 세도록 고침.
- `renameItem`이 `item_aliases` insert 다음에 `items.name` update를 하는데, update가 실패하면 이름은 안 바뀌었는데 별칭만 남는 문제가 있어(adversarial-reviewer 지적) update 실패 시 방금 넣은 별칭을 삭제하는 보정 로직을 추가함.

## 쉬운 설명

품목명을 바꿀 때, 옛날에 출력했던 송장에는 그때 이름을 그대로 두고, 정산서에는 새 이름으로 보여주는 기능이다. 이름이 바뀌어도 과거 송장 기록이 헷갈리지 않도록 하기 위함이다. 이 기능이 없으면 사업 초반부터 기록한 송장이 지금의 이름과 달라서 무엇이 진짜 이름인지 알기 어려워진다. 변경 전후를 미리 보여주고, 해당 품목이 몇 개 송장에 쓰였는지 영향 범위를 안내한다.
