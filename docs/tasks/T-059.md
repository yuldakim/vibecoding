## 목적

정산서의 뼈대를 만든다. 대상 기간·정렬·제외 규칙을 여기서 한 번에 확정한다.

## 요구사항 근거 (설계.md 인용)

> 모든 원청의 정산 기간은 매월 1일부터 말일까지다.
>
> 정산서 내역은 다음 순서로 정렬한다. 1. 납품일이 빠른 순서 2. 같은 날짜에는 송장번호가 빠른 순서
>
> 품목별 중간 합계는 표시하지 않는다.

## 작업 범위

- 원청·연월 기준 확정 송장 수집(취소 제외)
- 납품일 → 송장번호 순 정렬
- 송장 줄 단위로 그대로 나열(같은 품목도 합치지 않음)
- 각 줄에 적용 단가 해석 결과 부착
- 이월 대상 송장 포함(T-065 연계)

## 완료 기준

- [ ] 취소된 송장이 포함되지 않는다
- [ ] 정렬 순서가 요구사항과 정확히 일치한다
- [ ] 같은 날 같은 품목이 줄별로 따로 나온다
