## 목적

최근 사용만으로는 밀려나는 주력 품목을 사장님이 직접 고정하게 한다.

## 요구사항 근거 (설계.md 인용)

> 자주 사용하는 품목 즐겨찾기

## 작업 범위

- 품목 목록의 즐겨찾기 토글(큰 별 아이콘)
- 즐겨찾기 우선 정렬(즐겨찾기 > 최근 사용 > 이름순)
- 송장 작성 화면에서도 동일 정렬 적용

## 완료 기준

- [ ] 즐겨찾기 지정 시 최상단에 고정된다
- [ ] 해제하면 원래 정렬로 돌아간다
- [ ] 직원 화면에서도 같은 순서로 보인다
