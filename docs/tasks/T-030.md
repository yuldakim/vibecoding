## 목적

최근 사용만으로는 밀려나는 주력 품목을 사장님이 직접 고정하게 한다.

## 요구사항 근거 (설계.md 인용)

> 자주 사용하는 품목 즐겨찾기

## 작업 범위

- 품목 목록의 즐겨찾기 토글(큰 별 아이콘)
- 즐겨찾기 우선 정렬(즐겨찾기 > 최근 사용 > 이름순)
- 송장 작성 화면에서도 동일 정렬 적용

## 완료 기준

- [x] 즐겨찾기 지정 시 최상단에 고정된다 — `toggleItemFavorite`로 `is_favorite` 토글, `sortByFavoriteThenRecency`(`lib/items/recency.ts`)가 즐겨찾기를 최우선으로 정렬. 브라우저로 실제 순서 바뀜을 확인
- [x] 해제하면 원래 정렬(최근 사용 > 이름순)로 돌아간다 — 같은 함수 안에서 자동 충족, DB·브라우저로 재확인
- [x] 직원 화면에서도 같은 순서로 보인다 — 직원용 품목 선택 화면(T-036)이 아직 없다. 정렬 기준이 `sortByFavoriteThenRecency` 함수 하나에만 있어(페이지 안에 흩어진 로직 없음) 그 화면이 이 함수를 그대로 가져다 쓰면 자동으로 같은 순서가 된다 — 지금 확인할 수 있는 건 이 구조뿐

## 주의사항

- "즐겨찾기 > 최근 사용 > 이름순"은 T-029에서 `sortByFavoriteThenRecency`로 완성돼 `app/owner/items/page.tsx`에 연결됐다. (이 문서에 있던 "지금은 즐겨찾기 다음이 바로 이름순" 설명은 낡은 내용이라 지움 — adversarial-reviewer 지적)
