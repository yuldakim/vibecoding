# T-049 · 송장 상세·재출력

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-048](T-048.md) 확정 송장 목록 화면, [T-047](T-047.md) 인쇄 실행과 출력 시각 기록 |
| 요구사항 근거 | §8 출력과 취소, §25 송장 상세 및 재출력 |
| 주요 위치 | `app/invoices/[id]/` |

## 목적

종이를 잃어버리거나 추가로 필요할 때 동일한 출력물을 다시 뽑게 한다.

## 작업 범위

- 송장 상세 표시(수정 불가 상태 명시)
- 재출력 버튼
- 취소 버튼 진입점
- 내부 기록(작성·출력 시각)은 사장님에게만 표시

## 완료 기준

- [ ] 확정 송장에 수정 버튼이 없다
- [ ] 재출력이 동작하고 시각이 기록된다
- [ ] 직원 화면에 금액이 없다
