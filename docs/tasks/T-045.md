## 목적

원청 전달용과 공장 보관용을 한 장에 뽑아 잘라 쓰는 기존 업무 방식을 그대로 옮긴다.

## 요구사항 근거 (설계.md 인용)

> A4 한 장의 위쪽과 아래쪽에 같은 내용을 2부 배치한다.
>
> 가운데 절취선 표시
>
> 송장에는 봉제 단가와 금액을 표시하지 않는다.

## 작업 범위

- A4 인쇄용 CSS(@page, mm 단위)
- 상·하단 동일 송장 배치와 절취선
- 공장 정보·원청명·납품일·송장번호·품목 줄·전체 수량·받은 사람·서명·인수 날짜 영역
- 단가·금액 필드가 인쇄물에 없음을 확인

## 완료 기준

- [ ] 실제 A4 인쇄 시 상하 2부가 잘리지 않고 나온다
