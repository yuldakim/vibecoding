# T-056 · 송장 줄 ↔ 단가 자동 매칭

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 3. 봉제 단가 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-010](T-010.md) 마이그레이션: 월별 봉제 단가, [T-033](T-033.md) 여러 품목 합치기, [T-052](T-052.md) 단가 입력·수정 |
| 요구사항 근거 | §10 월별 봉제 단가, §11 예외 단가, §17 이월 |
| 주요 위치 | `lib/prices/resolve.ts` |

## 목적

정산 전체가 이 함수 하나에 달려 있다. 합쳐진 품목, 이월 송장, 예외 단가까지 우선순위를 명확히 정의한다.

## 요구사항 근거 (설계.md 인용)

> 단가를 한 번 입력하면 해당 월의 같은 품목·사이즈가 포함된 모든 송장 줄에 자동 적용한다.
>
> 단가는 실제 납품월인 7월 단가 적용

## 작업 범위

- 적용 우선순위 정의(줄 예외 단가 > 해당 월 기본 단가 > 미정)
- 합쳐진 품목은 최종 품목 단가로 해석
- 이월 송장은 실제 납품월 단가 적용
- 단가 없음(미정) 반환 규약

## 완료 기준

- [ ] 예외 단가가 있는 줄은 기본 단가를 쓰지 않는다
- [ ] 합쳐진 품목이 최종 품목 단가로 계산된다
- [ ] 이월 송장이 원래 납품월 단가로 계산된다

## 주의사항

- 이 로직은 단위 테스트(T-092) 대상이다. 분기별 케이스를 함수 주석에 적어 둔다.
