# T-072 · 엑셀 최종 품목명 병합 표시

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 엑셀·출력 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-071](T-071.md) 최종 정산 엑셀 생성, [T-033](T-033.md) 여러 품목 합치기 |
| 요구사항 근거 | §4 품목명 변경 규칙, §18 최종 정산 엑셀 |
| 주요 위치 | `lib/excel/settlement.ts` |

## 목적

원청은 하나의 이름으로 보길 원한다. 사이트 내부에 남은 이전 이름이 엑셀로 새어 나가면 안 된다.

## 요구사항 근거 (설계.md 인용)

> 월말 정산서에는 연결된 이전 품목들을 합쳐서 최종 품목명만 표시한다. 이전 이름은 원청에 보내는 엑셀에 표시하지 않는다.
>
> 품목 이름이 변경되거나 합쳐진 경우 최종 품목명만 표시한다.

## 작업 범위

- 송장 줄의 품목명 스냅샷 대신 최종 품목명으로 치환
- 합치기 체인 끝까지 해석
- 이전 이름이 엑셀 어디에도 없는지 검증
- 같은 최종 품목이어도 줄은 합치지 않음(줄별 표시 유지)

## 완료 기준

- [ ] 이름이 바뀐 품목이 새 이름으로만 엑셀에 나온다
- [ ] 합쳐진 품목 3개가 최종 품목명 하나로 표시된다
- [ ] 줄 수는 그대로 유지된다
