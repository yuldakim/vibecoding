# T-015 · 사장님 비밀번호 변경·초기화 절차

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 0. 기반 구축 |
| 분류 | 인증·권한 |
| 우선순위 | P2 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-014](T-014.md) 사장님 모드 비밀번호 인증 |
| 요구사항 근거 | §2 사장님 |
| 주요 위치 | `scripts/reset-owner-password.ts` |

## 목적

설계상 비밀번호 찾기 기능은 없고 개발자가 초기화한다. 그 절차를 사람 손에 맡기지 않고 스크립트로 고정한다.

## 요구사항 근거 (설계.md 인용)

> 사장님이 비밀번호를 잊은 경우 개발자에게 요청하여 초기화한다.

## 작업 범위

- 사장님 설정 화면의 비밀번호 변경 폼(현재 비밀번호 확인)
- 초기화 CLI 스크립트(환경변수로 새 비밀번호 주입)
- 초기화 시 audit_logs 기록
- 운영 문서에 절차 기록

## 완료 기준

- [ ] 사장님이 화면에서 비밀번호를 바꿀 수 있다
- [ ] 스크립트로 초기화하면 즉시 새 비밀번호로 로그인된다
- [ ] 새 비밀번호가 명령 이력이나 저장소에 남지 않는다
