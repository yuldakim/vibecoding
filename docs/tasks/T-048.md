# T-048 · 확정 송장 목록 화면

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-044](T-044.md) 송장 확정과 번호 부여, [T-028](T-028.md) 품목 검색(이전 이름 포함) |
| 요구사항 근거 | §25 확정 송장 목록 |
| 주요 위치 | `app/invoices/` |

## 목적

직원이 과거 송장을 다시 뽑거나 확인할 때 쓰는 화면이다. 품목 검색은 이전 이름도 함께 걸려야 한다.

## 작업 범위

- 기간·원청 필터와 기본값(최근 1개월)
- 송장번호 직접 검색
- 품목명 검색(이전 이름 포함)
- 취소된 송장 표시 구분
- 페이지네이션

## 완료 기준

- [ ] 송장번호로 한 건이 바로 찾아진다
- [ ] 옛 품목명으로 검색해도 해당 송장이 나온다
- [ ] 취소된 송장이 시각적으로 구분된다

## 주의사항

- 직원 화면이므로 목록 어디에도 금액이 나오면 안 된다.
