# T-069 · 단가 확인 요청 엑셀 생성

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 엑셀·출력 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-054](T-054.md) 단가 미정 목록 |
| 요구사항 근거 | §12 단가 미정 처리 |
| 주요 위치 | `lib/excel/price-request.ts` |

## 목적

원청 담당자가 받아서 그 자리에서 채워 보낼 수 있는 형태여야 한다. 원청 한 곳당 파일 하나로 모은다.

## 요구사항 근거 (설계.md 인용)

> 단가 확인 요청 엑셀에 포함할 내용: 품목명, 사이즈, 적용 월, 납품일, 송장번호, 납품 수량, 단가 입력란
>
> 같은 원청의 단가 미정 품목은 한 개의 엑셀 파일에 모은다.

## 작업 범위

- 엑셀 생성 라이브러리 선정과 설치(exceljs 등)
- 요구된 7개 열 구성과 단가 입력란 빈 칸
- 원청별 단일 파일 생성
- 열 너비·머리말 등 읽기 편한 서식
- 파일명 규칙 정의

## 완료 기준

- [ ] 미정 항목이 하나도 빠지지 않고 들어간다
- [ ] 단가 입력란이 비어 있고 입력 가능하다
- [ ] 엑셀에 금액 계산식이 섞여 들어가지 않는다
