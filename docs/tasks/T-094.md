| 분류 | 인프라·배포 |

| 예상 시간 | 30분 |
| 선행 작업 | [T-003](T-003.md) Supabase 프로젝트 연결, [T-073](T-073.md) 이메일 발송 인프라 구축, [T-075](T-075.md) 정산서 자동 발송 스케줄러, [T-001](T-001.md) 프로젝트 기본 정보·운영 계정 확정 |

## 목적

자동 발송은 배포 환경에서만 실제로 돈다. 로컬에서 되는 것으로는 끝난 게 아니다.

## 작업 범위

- Vercel 프로젝트 연결과 배포
- 환경변수 전체 설정(Supabase·이메일·사장님 비밀번호 해시)
- Cron 일정 등록과 인증 토큰 설정
- 도메인 연결
- 운영 환경에서 테스트 발송 1회 확인

## 완료 기준

- [ ] 운영 URL에서 로그인·송장 작성이 동작한다
- [ ] Cron이 실제로 예정 시각에 실행된 로그가 있다
- [ ] 운영 환경에서 테스트 메일이 도착한다
- [ ] 비밀 값이 저장소에 없다

## 주의사항

- Supabase 무료 요금제의 자동 일시정지가 Cron 실패로 이어질 수 있다. 요금제를 확인한다.
