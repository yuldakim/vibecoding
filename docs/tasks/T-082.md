# T-082 · 수정 정산서 확인·승인·발송 화면

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-081](T-081.md) 발송본과 수정본 변경 내역 자동 비교, [T-074](T-074.md) 이메일 문구 치환과 발송 전 편집 |
| 요구사항 근거 | §21 발송 완료 후 수정 정산서, §25 수정 정산서 비교 |
| 주요 위치 | `app/owner/settlements/[id]/revision/` |

## 목적

자동 비교 결과가 항상 적절한 문장은 아니다. 사장님이 원청에 보낼 설명을 다듬을 수 있어야 한다.

## 요구사항 근거 (설계.md 인용)

> 사장님은 자동 생성된 변경 내용을 확인하고 문구를 수정할 수 있다.
>
> 수정 정산서도 사장님이 다시 최종 확인한 후 발송한다.

## 작업 범위

- 최초본 vs 수정본 나란히 비교 표시
- 자동 생성된 변경 문구 편집
- 최종 승인과 발송
- 변경 문구를 이메일 본문에 포함

## 완료 기준

- [ ] 변경 문구를 수정해 발송할 수 있다
- [ ] 승인 없이는 발송 버튼이 동작하지 않는다
- [ ] 발송 후 수정본도 이력에 남는다
