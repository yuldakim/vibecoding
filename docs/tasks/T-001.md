# T-001 · 프로젝트 기본 정보·운영 계정 확정

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 0. 기반 구축 |
| 분류 | 문서·운영 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | 없음 |
| 요구사항 근거 | §19 이메일 발송, §23 공장 정보 |

## 목적

코드로 결정할 수 없는 운영 값들을 먼저 모은다. 이 값이 없으면 이메일 발송·공장 정보 표시·배포가 전부 막히므로 백로그 맨 앞에 둔다.

## 요구사항 근거 (설계.md 인용)

> 사이트 전용 이메일 주소를 새로 만들어 사용한다.
>
> 종이 송장과 정산 엑셀에 표시할 공장 정보: 공장명, 대표자명, 사업자등록번호, 주소, 전화번호

## 작업 범위

- 공장 정보 5개 항목 실제 값 수집
- 사이트 전용 이메일 주소 개설 여부와 주소 확정
- 배포 도메인(또는 vercel.app 서브도메인) 확정
- 사장님 모드 초기 비밀번호 전달 방법 합의

## 완료 기준

- [ ] 4개 항목이 모두 값으로 적혀 이 문서에 기록됐다
- [ ] 이메일 주소가 실제로 로그인 가능한 상태다
- [ ] T-002·T-019·T-073의 blocked 사유가 해소됐다

## 주의사항

- 비밀번호·API 키 실제 값은 이 문서나 저장소에 적지 않는다. 환경변수로만 다룬다.

## 사람이 결정해야 할 것

- 사이트 전용 이메일을 Gmail로 만들지, 도메인 메일로 만들지
- 공장 사업자등록번호·주소의 정확한 표기
- 배포 도메인을 새로 살지 여부
