# T-052 · 단가 입력·수정

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 3. 봉제 단가 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-051](T-051.md) 월별 단가 관리 화면 |
| 요구사항 근거 | §10 월별 봉제 단가, §11 예외 단가 |
| 주요 위치 | `app/owner/prices/` |

## 목적

사장님이 가장 자주 하는 입력 작업이다. 입력 즉시 저장되고 실수는 되돌릴 수 있어야 한다.

## 작업 범위

- 표 안 인라인 입력과 즉시 저장
- 정수(원) 검증과 천 단위 구분 표시
- 변경 시 이전 값·새 값·시각 기록
- 저장 성공·실패 피드백

## 완료 기준

- [ ] 입력한 단가가 새로고침 후에도 유지된다
- [ ] 소수점·음수가 저장되지 않는다
- [ ] 변경 이력이 조회된다
