## 목적

정산 금액의 출발점이다. 어떤 조합에 단가가 있고 없는지 한눈에 보이게 한다.

## 요구사항 근거 (설계.md 인용)

> 봉제 단가는 다음 조건으로 관리한다: 원청, 품목, 사이즈, 적용 연도와 월

## 작업 범위

- 원청·연월 선택
- 품목×사이즈 단가표 렌더링
- 미정 항목 강조 표시
- 품목명 검색·필터
- 단가가 공급가액 기준(부가세 별도)임을 화면에 명시

## 완료 기준

- [ ] 선택한 월의 단가가 표로 보인다
- [ ] 미정 항목이 눈에 띄게 구분된다
- [ ] 품목 100개 규모에서 화면이 쓸 만하다
