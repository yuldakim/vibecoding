## 목적

이월은 날짜를 바꾸는 것이 아니라 표시 위치만 옮기는 것이다. 단가도 실제 납품월 기준이어야 원청과 금액이 맞는다.

## 요구사항 근거 (설계.md 인용)

> 납품일은 7월 31일 그대로 표시
>
> 비고 또는 구분에 `전월 이월` 표시
>
> 단가는 실제 납품월인 7월 단가 적용
>
> 이월 송장의 실제 납품월 단가가 없으면 단가 미정 목록에 포함한다.

## 작업 범위

- 이월 줄에 실제 납품일 유지
- '전월 이월' 표시(화면·엑셀 공통)
- 실제 납품월 단가로 계산
- 해당 월 단가가 없으면 미정 목록에 포함

## 완료 기준

- [ ] 8월 정산서에 7월 31일 납품일이 그대로 보인다
- [ ] 이월 줄에 전월 이월 표시가 있다
- [ ] 7월 단가가 없으면 미정 목록에 뜬다
