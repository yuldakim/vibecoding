# T-022 · 원청 등록·수정 폼

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 1. 마스터 데이터 |
| 분류 | 기능 구현 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-021](T-021.md) 원청 목록 화면 |
| 요구사항 근거 | §3 원청 관리 |
| 주요 위치 | `app/owner/clients/[id]/` |

## 목적

정산서 이메일이 담당자에게 정확히 가야 하므로 이메일 형식 검증이 중요하다.

## 요구사항 근거 (설계.md 인용)

> 원청별 저장 정보: 업체명, 담당자명, 담당자 이메일, 전화번호, 주소 또는 납품 장소

## 작업 범위

- 5개 기본 항목 입력·검증
- 이메일 형식 검증과 오타 경고
- 저장 후 목록 갱신
- 변경 시 audit_logs 기록

## 완료 기준

- [ ] 잘못된 이메일 형식이 저장되지 않는다
- [ ] 필수 항목 누락 시 어떤 항목인지 큰 글씨로 안내된다
- [ ] 수정 내용이 즉시 반영된다

## 주의사항

- 담당자는 원청당 한 명이라는 전제라 복수 담당자 UI를 만들지 않는다.
