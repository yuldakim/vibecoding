## 목적

기능이 다 돼도 사용자가 못 쓰면 실패다. 한 달 주기(송장 → 단가 → 정산 → 발송)를 통째로 리허설한다.

## 작업 범위

- 직원 시나리오(송장 작성·출력·취소·재출력)
- 사장님 시나리오(단가 입력·미정 요청·정산 승인·발송·수정 정산서)
- 이월 시나리오 포함
- 화면 사진이 들어간 1~2장짜리 사용 안내
- 1차 범위 제외 기능 안내

## 완료 기준

- [ ] 두 시나리오를 실제 사용자와 끝까지 돌렸다
- [ ] 발견된 문제가 백로그에 새 작업으로 등록됐다
- [ ] 사용 안내를 인쇄해 공장에 둘 수 있다
