# T-074 · 이메일 문구 치환과 발송 전 편집

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 이메일·알림 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-073](T-073.md) 이메일 발송 인프라 구축, [T-024](T-024.md) 원청별 이메일 기본 문구 설정 |
| 요구사항 근거 | §19 이메일 발송 |
| 주요 위치 | `app/owner/email/compose/` |

## 목적

매번 같은 문구를 쓰되 필요할 때는 한마디 덧붙일 수 있어야 한다.

## 요구사항 근거 (설계.md 인용)

> 자동으로 삽입할 수 있는 항목: 원청 업체명, 정산 연도, 정산 월, 파일명, 수정본 여부
>
> 사장님은 실제 발송 전에 이메일 제목과 본문을 직접 수정할 수 있다.

## 작업 범위

- 토큰 치환 엔진(5종)
- 발송 직전 제목·본문 편집 화면
- 편집 내용은 이번 발송에만 적용(기본 문구는 유지)
- 수정본 여부 토큰 처리

## 완료 기준

- [ ] 치환된 제목·본문이 실제 발송 내용과 같다
- [ ] 발송 시 편집해도 원청 기본 문구가 바뀌지 않는다
- [ ] 수정 정산서 발송 시 수정본 표시가 들어간다
