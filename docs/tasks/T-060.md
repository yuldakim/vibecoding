## 목적

부가세를 줄마다 계산하면 합계가 달라진다. 전체 공급가액을 합산한 뒤 한 번만 계산하고 원 단위 반올림한다.

## 요구사항 근거 (설계.md 인용)

> 각 내역의 공급가액: 수량 × 적용 단가
>
> 부가세는 전체 공급가액을 합산한 뒤 한 번 계산하고 원 단위에서 반올림한다.
>
> 최종 합계: 전체 공급가액 + 부가세

## 작업 범위

- 줄별 공급가액 = 수량 × 적용 단가(정수 연산)
- 전체 공급가액 합산
- 부가세 = 전체 공급가액 × 10%, 원 단위 반올림
- 최종 합계 산출
- 미정 단가가 있을 때의 합계 처리 규칙

## 완료 기준

- [ ] 줄별 부가세를 합산한 값이 아니라 전체 기준으로 계산된다
- [ ] 반올림이 원 단위에서 한 번만 일어난다
- [ ] 부동소수점 오차가 발생하지 않는다

## 주의사항

- 원 단위 반올림 기준(0.5 올림)을 코드 주석에 명시한다. 회계상 분쟁 소지가 있는 부분이다.
