# T-029 · 최근 사용 품목 우선 표시

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 1. 마스터 데이터 |
| 분류 | 기능 구현 |

| 예상 시간 | 30분 |
| 선행 작업 | [T-026](T-026.md) 원청별 품목 목록 화면 |

## 목적

100개 목록에서 매번 검색하지 않고 자주 쓰는 품목을 바로 고르게 한다.

## 요구사항 근거 (설계.md 인용)

> 최근 사용 품목 우선 표시

## 작업 범위

- 송장 확정 시 품목의 최근 사용 시각 갱신
- 원청별 최근 사용 순 정렬
- 최근 사용 상위 N개 섹션 분리 표시

## 완료 기준

- [ ] 직전 송장에 쓴 품목이 목록 최상단에 온다
- [ ] 원청이 바뀌면 그 원청의 최근 사용으로 바뀐다
- [ ] 최근 사용이 없으면 이름순으로 정렬된다
