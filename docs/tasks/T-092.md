## 목적

정산 금액이 틀리면 돈 문제가 된다. 손으로 확인할 수 없는 조합을 테스트로 고정한다.

## 작업 범위

- 부가세 전체 합산 후 1회 반올림 검증
- 예외 단가가 해당 줄에만 적용되는지 검증
- 이월 줄이 실제 납품월 단가를 쓰는지 검증
- 합쳐진 품목의 단가 해석 검증
- 미정 단가 포함 시 동작 검증

## 완료 기준

- [ ] 줄별 부가세 합산과 다른 결과가 나오는 케이스가 테스트로 잡힌다
- [ ] 5개 시나리오가 모두 통과한다
- [ ] CI에서 자동 실행된다
