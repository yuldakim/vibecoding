# T-078 · 발송 실패 감지와 알림 생성

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 5. 엑셀·이메일 |
| 분류 | 이메일·알림 |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-073](T-073.md) 이메일 발송 인프라 구축, [T-083](T-083.md) 알림 생성 규칙 구현 |
| 요구사항 근거 | §20 발송 실패 처리 |
| 주요 위치 | `lib/email/failure.ts` |

## 목적

정산서가 안 갔다는 사실을 아무도 모르는 상황을 막는다. 직원에게는 금액 없이 사실만 알린다.

## 요구사항 근거 (설계.md 인용)

> 사장님 화면: 발송 실패 원청, 실패 시각, 가능한 경우 실패 이유, 다시 보내기 버튼
>
> 직원 화면: `사장님께 알려주세요`, 원청명, 정산서 발송 실패 안내

## 작업 범위

- 발송 실패 시 알림 레코드 생성
- 사장님용 알림(원청·시각·사유·재발송 버튼)
- 직원용 알림(금액 없이 원청명과 안내 문구만)
- 실패 사유 문자열 저장과 사람이 읽을 수 있는 변환

## 완료 기준

- [ ] 발송 실패 시 두 역할 화면에 모두 알림이 뜬다
- [ ] 직원 알림에 금액·단가가 전혀 없다
- [ ] 실패 사유가 표시된다
