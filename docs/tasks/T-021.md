## 목적

원청은 모든 기능의 시작점이다. 목록에서 한눈에 상태와 정산 일정을 파악하게 한다.

## 작업 범위

- 원청 목록 표(업체명·담당자·발송일·상태)
- 업체명 검색
- 사용 중지 포함/제외 필터
- 행 클릭 시 상세·수정 진입

## 완료 기준

- [ ] 원청 20곳 이상에서도 목록이 느려지지 않는다
- [ ] 사용 중지 원청이 시각적으로 구분된다
- [ ] 휴대폰 폭에서 표가 카드 형태로 읽힌다
