# T-043 · 송장 최종 확인 화면

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 2. 송장 |
| 분류 | 화면·UX |
| 우선순위 | P0 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-037](T-037.md) 송장 줄: 사이즈 선택·수량 입력, [T-038](T-038.md) 송장 줄: 비고 입력과 줄 분리 규칙, [T-040](T-040.md) 납품 날짜 선택 |
| 요구사항 근거 | §6 송장 작성, §25 송장 최종 확인 |
| 주요 위치 | `app/invoices/[id]/confirm/` |

## 목적

확정하면 수정이 불가능하므로 이 화면이 마지막 방어선이다. 인쇄될 모습 그대로 보여준다.

## 요구사항 근거 (설계.md 인용)

> 최종 내용 확인
>
> 출력한 송장은 수정할 수 없다.

## 작업 범위

- 원청·납품일·품목 줄·전체 수량 요약 표시
- '확정하면 수정할 수 없습니다' 경고
- 수정하러 돌아가기 버튼
- 확정하고 인쇄 버튼(중복 클릭 방지)

## 완료 기준

- [ ] 확정 전 모든 입력값이 한 화면에서 확인된다
- [ ] 확정 버튼을 두 번 눌러도 송장이 하나만 생긴다
- [ ] 경고 문구가 큰 글씨로 보인다
