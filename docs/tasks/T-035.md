## 목적

원청을 먼저 골라야 그 원청의 품목만 나온다. 첫 화면이므로 조작이 가장 단순해야 한다.

## 요구사항 근거 (설계.md 인용)

> 원청을 선택하면 해당 원청에 등록된 품목만 표시한다.

## 작업 범위

- 활성 원청 큰 버튼 목록
- 원청이 많을 때의 검색
- 선택 후 작성 화면 이동과 선택 유지
- 사용 중지 원청 제외

## 완료 기준

- [ ] 사용 중지된 원청이 선택지에 없다
- [ ] 선택 후 뒤로 가도 선택이 유지된다
- [ ] 휴대폰에서 한 손으로 누를 수 있는 크기다
