# T-053 · 지난달 단가표 복사

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 3. 봉제 단가 |
| 분류 | 기능 구현 |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-051](T-051.md) 월별 단가 관리 화면 |
| 요구사항 근거 | §10 월별 단가표 생성 |
| 주요 위치 | `app/owner/prices/copy/` |

## 목적

매달 100개 단가를 다시 입력할 수 없다. 복사 후 바뀐 것만 고치는 흐름을 만든다.

## 요구사항 근거 (설계.md 인용)

> 새로운 달의 단가표를 만들 때 지난달 단가를 복사할 수 있다.
>
> 아직 정해지지 않은 단가는 `미정`으로 유지

## 작업 범위

- 복사 원본 월 선택과 미리보기(몇 건 복사되는지)
- 이미 값이 있는 항목의 덮어쓰기 여부 선택
- 지난달 미정 항목은 미정으로 복사
- 복사 결과 요약 표시

## 완료 기준

- [ ] 복사 후 새 달 단가표가 채워진다
- [ ] 기존 입력값을 실수로 덮어쓰지 않는다
- [ ] 복사 건수가 사전에 표시된다
