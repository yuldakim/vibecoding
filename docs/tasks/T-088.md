## 목적

사이트에 들어왔을 때 가장 먼저 보는 화면이다. 설명 없이도 뭘 눌러야 할지 알아야 한다.

## 작업 범위

- 직원 계정 큰 버튼 목록
- '사장님 모드' 버튼과 비밀번호 화면 연결
- 마지막 선택 계정 기억(기기별)
- 계정이 없을 때의 안내

## 완료 기준

- [x] 처음 보는 사람도 설명 없이 진입한다 — 브라우저로 확인: "누구세요?" 제목 아래 "직원"/"사장님" 두 구역, 이름이 곧 버튼 라벨
- [x] 사장님 모드가 직원 계정과 시각적으로 구분된다 — 구분선(border-t)으로 섹션 분리, 직원은 큰 파란 버튼, 사장님 모드는 테두리만 있는 버튼으로 스타일 다름(스크린샷으로 확인)
- [x] 직원 계정이 하나도 없으면 안내가 나온다 — 코드 확인(`accounts?.length` 분기) + 실제로 테스트 계정 정리 후 안내 문구가 뜨는 경로 확인

## 주의사항

- **(리뷰에서 발견해 수정함)** 처음 만들었을 때 `/select`가 어디서도 연결이 안 돼 있었다 — T-013이 만든 `/staff`가 여전히 모든 로그인·로그아웃 리다이렉트 대상이라, 실제로는 아무도 이 화면에 못 들어왔다. 지금은 `/staff`가 `/select`로 리다이렉트만 하는 얇은 페이지가 됐고(계정 목록·조회 로직은 `app/(auth)/staff/actions.ts`에 그대로 남아 재사용됨), `selectStaffAccount`·`logoutStaff`의 리다이렉트도 전부 `/select`를 가리키게 고쳤다. 새 화면을 "만들었다"와 "실제로 그 경로가 진입점이다"는 다른 이야기다 — 리다이렉트 체인을 항상 끝까지 따라가서 확인한다.
- `app/page.tsx`(루트)는 아직 `/select`로 안 보낸다("준비 중" 정적 문구) — 이건 T-018(역할별 네비게이션과 라우트 가드) 범위다.
