# T-088 · 사용자 선택 화면

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 6. 알림·화면·마무리 |
| 분류 | 화면·UX |
| 우선순위 | P1 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-013](T-013.md) 직원 로그인(계정 선택 방식), [T-014](T-014.md) 사장님 모드 비밀번호 인증 |
| 요구사항 근거 | §25 공통 화면 |
| 주요 위치 | `app/(auth)/select/` |

## 목적

사이트에 들어왔을 때 가장 먼저 보는 화면이다. 설명 없이도 뭘 눌러야 할지 알아야 한다.

## 작업 범위

- 직원 계정 큰 버튼 목록
- '사장님 모드' 버튼과 비밀번호 화면 연결
- 마지막 선택 계정 기억(기기별)
- 계정이 없을 때의 안내

## 완료 기준

- [ ] 처음 보는 사람도 설명 없이 진입한다
- [ ] 사장님 모드가 직원 계정과 시각적으로 구분된다
- [ ] 직원 계정이 하나도 없으면 안내가 나온다
