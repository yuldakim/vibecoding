> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 주요 위치 | `app/owner/prices/paste/` |

## 목적

회신 엑셀을 보고 한 칸씩 옮겨 적는 일을 없앤다. 자동 수집은 범위 밖이지만 붙여넣기는 범위 안이다.

## 요구사항 근거 (설계.md 인용)

> 여러 단가를 한꺼번에 복사·붙여넣을 수 있는 입력 방식도 제공한다.

## 작업 범위

- 탭/줄바꿈 구분 텍스트 파싱
- 품목·사이즈 매칭과 매칭 실패 항목 표시
- 적용 전 미리보기와 확인
- 일괄 저장과 이력 기록

## 완료 기준

- [ ] 엑셀에서 복사한 여러 줄이 한 번에 반영된다
- [ ] 매칭 실패 줄이 명확히 표시되고 저장되지 않는다
- [ ] 적용 전에 몇 건이 바뀌는지 보인다

## 주의사항

- 이메일·엑셀에서 단가를 자동 추출하는 기능은 1차 범위 제외다. 사람이 복사해 붙이는 것까지만 한다.
