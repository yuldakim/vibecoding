# T-031 · 품목 숨김·다시 사용

> 작업 상태의 SSOT는 저장소 루트의 `backlog.json`이다. 이 문서는 무엇을 왜 어떻게 만드는지만 다룬다.

| 항목 | 값 |
| --- | --- |
| 단계 | 1. 마스터 데이터 |
| 분류 | 기능 구현 |
| 우선순위 | P2 |
| 예상 시간 | 30분 |
| 선행 작업 | [T-026](T-026.md) 원청별 품목 목록 화면 |
| 요구사항 근거 | §4 품목 관리, §24 데이터 보존 원칙 |
| 주요 위치 | `app/owner/items/` |

## 목적

선택 목록을 짧게 유지하되 과거 송장과 정산에는 영향을 주지 않는다.

## 요구사항 근거 (설계.md 인용)

> 생산 종료 품목 숨김
>
> 숨긴 품목 다시 사용

## 작업 범위

- 숨김 토글과 확인
- 숨김 품목은 송장 작성 선택지에서 제외
- 숨김 품목의 과거 송장·정산은 정상 조회
- 숨김 목록 화면과 복구

## 완료 기준

- [ ] 숨기면 송장 작성 목록에서 사라진다
- [ ] 숨긴 품목의 과거 송장이 그대로 조회된다
- [ ] 복구하면 즉시 다시 선택된다
